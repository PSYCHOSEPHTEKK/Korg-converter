# Korg Electribe 2 WAV-Konverter

Ein kleiner, vollständig lokal arbeitender Browser-Konverter für MP3-Dateien.

## Vorteile

- Keine Uploads — die Datei bleibt auf dem Gerät
- Mono-Ausgabe reduziert die Dateigröße
- 44.1 kHz ist optimal für den Sampler
- Optional begrenzte Länge
- 16-Bit-PCM-WAV-Ausgabe

## Nutzung

Die GitHub-Pages-Seite öffnen, MP3 auswählen und "MP3 in WAV konvertieren" anklicken.
Der Browser erzeugt anschließend einen Download-Link.

Empfohlen für die Korg Electribe 2: **Mono, 44.1 kHz**.
