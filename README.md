# Korg Electribe 2 WAV-Konverter

Ein kostenloser Browser-Konverter für manuell ausgewählte Audio- und Videoausschnitte. Die Dateien werden lokal im Browser verarbeitet und nicht hochgeladen.

## So geht's

1. Öffne die GitHub-Pages-Seite des Projekts.
2. Wähle eine Audio- oder Videodatei aus.
3. Trage bei **Startzeit** ein, ab welcher Sekunde der Ausschnitt beginnen soll.
4. Trage bei **Länge des Ausschnitts** die gewünschte Dauer ein. Sie darf höchstens **10 Sekunden** betragen.
5. Wähle **Mono** für eine kleinere Datei und **44.1 kHz**.
6. Klicke **Ausschnitt als WAV speichern** und anschließend auf **WAV herunterladen**.

Für Audio- und Videodateien hängt die Unterstützung von den Formaten ab, die der Browser auf deinem Gerät abspielen kann. Bei Videos wird nur die Tonspur exportiert. Bei manchen Videoformaten, insbesondere MKV, kann der Browser die Audiospur möglicherweise nicht lesen.

WAV-Dateien sind unkomprimiert. Bei Mono, 44.1 kHz und 16-Bit ist ein 10-Sekunden-Ausschnitt ungefähr 860 KB groß.
